## <img src="https://media.giphy.com/media/LmNwrBhejkK9EFP504/giphy.gif" width="28"> &nbsp;Featured Projects

<details>
<summary><b>🚀 &nbsp;Aether — Distributed AI Inference Gateway</b></summary>

<br/>

A high-throughput inference gateway that routes, batches, and caches LLM requests across multiple model backends with token-level streaming and per-tenant rate limiting.

| Aspect | Detail |
| :--- | :--- |
| **Stack** | Go · gRPC · Redis · PostgreSQL · Kubernetes · Prometheus |
| **Scale** | 12k+ req/min sustained · 40+ concurrent model backends |
| **Performance** | p99 latency ↓ 63% via adaptive request batching + KV-cache reuse |
| **Security** | mTLS between services · per-tenant API keys · signed request auditing |
| **Impact** | Cut inference infra cost ~38% while raising throughput 2.4× |
| **Repository** | [`github.com/Atul-Kaushall/aether`](https://github.com/Atul-Kaushall) |

Built to solve the "too many models, too little GPU" problem: a smart routing layer that collapses bursty traffic into optimally-sized batches, reuses attention caches across similar prompts, and gracefully degrades under backend failure with circuit breakers and hedged requests.

</details>

<details>
<summary><b>🧩 &nbsp;Helios — Real-Time Event Processing Platform</b></summary>

<br/>

An event-driven backbone ingesting millions of events/day with exactly-once processing guarantees, replayable streams, and a self-serve rules engine for downstream teams.

| Aspect | Detail |
| :--- | :--- |
| **Stack** | Java · Spring Boot · Kafka · Cassandra · Docker · Grafana |
| **Scale** | 5M+ events/day · 200+ downstream consumers |
| **Performance** | Sub-100ms end-to-end enrichment at the 95th percentile |
| **Security** | RBAC on stream topics · encrypted-at-rest payloads · full audit trail |
| **Impact** | Replaced 3 brittle cron pipelines · reduced data-freshness lag from hours to seconds |
| **Repository** | [`github.com/Atul-Kaushall/helios`](https://github.com/Atul-Kaushall) |

A partitioned, backpressure-aware pipeline with idempotent consumers and a dead-letter recovery workflow — designed so a single poisoned message never stalls the stream, and any window can be replayed deterministically.

</details>

<details>
<summary><b>🌐 &nbsp;Nova — Full-Stack SaaS Analytics Suite</b></summary>

<br/>

A multi-tenant analytics platform with a real-time dashboard, embeddable widgets, and a query engine that keeps p95 dashboard loads under half a second on large datasets.

| Aspect | Detail |
| :--- | :--- |
| **Stack** | Next.js · TypeScript · Node.js · PostgreSQL · Redis · AWS |
| **Scale** | Multi-tenant · 300+ workspaces · 10M+ rows queried live |
| **Performance** | p95 dashboard load < 480ms via materialized views + edge caching |
| **Security** | Row-level tenant isolation · JWT + refresh rotation · CSP-hardened frontend |
| **Impact** | Powered self-serve analytics for internal teams, retiring a paid third-party tool |
| **Repository** | [`github.com/Atul-Kaushall/nova`](https://github.com/Atul-Kaushall) |

Tenant isolation enforced at the database row level, incremental materialized views for hot metrics, and an edge-cached read path — so adding the 300th workspace costs the same as the 3rd.

</details>

<details>
<summary><b>🔐 &nbsp;Sentinel — Zero-Trust Auth & Access Service</b></summary>

<br/>

A centralized authentication and fine-grained authorization service with short-lived tokens, device attestation, and policy-as-code access rules.

| Aspect | Detail |
| :--- | :--- |
| **Stack** | Python · FastAPI · PostgreSQL · Redis · OPA · Docker |
| **Scale** | 50k+ daily active identities · 1k+ policy evaluations/sec |
| **Performance** | < 15ms authorization decisions via compiled policy + Redis session cache |
| **Security** | Zero-trust model · short-lived JWTs · OPA policy-as-code · full audit logging |
| **Impact** | Unified auth across 8 internal services · eliminated 4 bespoke login flows |
| **Repository** | [`github.com/Atul-Kaushall/sentinel`](https://github.com/Atul-Kaushall) |

Every request is untrusted by default: identities carry short-lived tokens, authorization is evaluated against versioned Open Policy Agent rules, and each decision is logged for a complete, queryable access trail.

</details>
